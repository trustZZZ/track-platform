# Ограничения проекта (template-fullstack)

ИИ-агент обязан соблюдать эти ограничения; нарушение = возврат работы.

## 1. Запрещённые зависимости и инструменты

| Запрещено                             | Причина / альтернатива                           |
| ------------------------------------- | ------------------------------------------------ |
| `requests` в backend                  | async HTTP через `httpx`                         |
| Один общий `node_modules` в корне     | подсистемы изолированы: `frontend/`              |
| `redux` без необходимости             | предпочтителен минимум состояния (Context/hooks) |
| Не-nginx раздача статики без карточки | стек раздачи фиксирован                          |

## 2. Запрещённые паттерны

- Прямые `fetch` к `:8000` с фронтенда (только через `/api`).
- Дублирование типов вручную: контракт — Pydantic на backend + `client.ts` на
  frontend, синхронизация через карточку.
- Секреты в `VITE_*` (попадают в публичный бандл).
- Слепые `except` на backend; необработанные `fetch`-ошибки на frontend.
- Односторонние изменения контракта (backend без frontend и наоборот).

## 3. Границы ответственности модулей

- Backend `src/app/` — API и бизнес-логика; не знает о React.
- Frontend `src/api/` — единственное место HTTP-вызовов.
- Frontend `src/` компоненты — рендер и состояние; вызовы только через `src/api/`.
- `nginx.conf` — маршрутизация `/api` и SPA-fallback; менять через карточку.

## 4. Требования к тестам

- Backend: покрытие >= 70% (`pytest-cov`), тесты через `ASGITransport`.
- Frontend: Vitest; `tsc -b` обязателен (strict);
  API-клиент тестируется с мокнутным `fetch`.
- Тесты не зависят от сети и docker-compose.

## 5. Критерии готовности (Definition of Done)

- [ ] Backend: `ruff`, `mypy`, `pytest` зелёные.
- [ ] Frontend: `tsc -b`, `vitest run`, `build` зелёные.
- [ ] Контракт синхронизирован (backend-схема ↔ TS-типы).
- [ ] `docker compose config` валиден при изменении compose.
- [ ] `TECHNICAL.md` / `README.md` актуальны.
- [ ] Карточка переведена в `review`.

## 6. Внешние сервисы

- Отсутствуют по умолчанию. БД/очереди/авторизация — только через карточку.
